# 微信小程序的页面构思与打磨

适用于首版范围已确认的新小程序，或用户明确要求的整体改版。评一张图时，直接给页面判断。改一个控件、修遮挡或加复制功能时，沿用当前页面，验证受影响动作即可。

## 从用户手里的东西起笔

先写一句具体任务。例如「午休时，学生要找今天 14 点还有座位、能步行过去的自习室」。选出会改变决定的真实字段、首屏要看的信息、下一步动作、常见失败情况。沿用当前项目确认过的偏好；给某场活动选过的颜色，只在有相同品牌约定时带到下一页。

新设计在内部先构思六种排法，可以分别从用户认得的物件、相近服务的真实操作、完全不同领域但相同的决策问题切入。每种用一行记下「先看到什么、凭什么决定、接着怎么做、牺牲什么」。删掉仅换色、只调圆角、依赖缺失数据或需要扩张业务的候选。挑三种有代表性的做成可看的同页方案；六个构思留在设计过程中，用户只比较三种成形的方向。简单任务里操作顺序已很明确时，可比较信息密度、主次关系、单手可达性，直接说清哪些步骤相同。

## 按实际困难选表现方式

| 用户在判断什么 | 可以试的结构 | 在微信里怎么验证 |
| --- | --- | --- |
| 哪件物品是我丢的 | 有授权实拍时按物品外观浏览，图旁保留日期地点；缺图的记录照常能找 | 两个相似物品能靠文字区分；图片失败仍能读清时间地点 |
| 我现在来得及参加哪一场 | 同日场次按时间排；跨日再分组；用长度表示时长时同时写起止时间 | 小屏可直接比较两场；售罄、跨日和长标题仍然读得懂 |
| 我离哪个入口最近 | 有可靠地点数据时按楼栋分组或提供位置关系图；保留可读地名作为入口 | 拒绝定位也能手动找到楼栋；用不到地图时选普通分组列表 |
| 我的凭证现在能做什么 | 把取件码、有效时间和复制放在同一张凭证上；稳定的版式可以成为品牌特征 | 用单手复制原值；过期时换成文字状态和下一步，避免沿用有效态动作 |
| 哪些状态需要注意 | 颜色在全项目对应同一含义，同时用文字或图形区分。角色形象只用于确能解释状态的反馈 | 遮住色彩仍能区分候补与成功；关动效后结果可读 |
| 照片、作品或文字谁是主角 | 画廊给作品足够面积；问答列表优先展示问题和有用的回答摘要 | 用长短不一的真实文案走查，检查首屏是否被装饰或重复标题占满 |
| AI 应在哪一步帮忙 | 仅在已确认的 AI 功能内，把识别、提取或改写放在对应物件或字段旁，结果可改 | 识别失败或用户跳过时依然能手工填写；检查额外费用与等待是否值得 |
| 手上只有一只手或看不清小字怎么办 | 让主操作靠近使用位置；手势有可点替代，保留字级和留白 | 大字、短屏和键盘弹出时仍能读、点、返回；按下后有清楚的结果 |

离线打开[自习室三种排法](../assets/mobile-directions.html)，比较同一批房间按时段、楼栋和余位组织时的差别。样张用于学习如何构思；下个项目从它自己的字段和任务起步。

## 取参考、定素材

- 看已有产品或用户给的参考图时，挑一个能解释的具体关系，例如「余位紧挨时段」或「名称与状态共用一行」。有原图才能记录图文比例、首屏条数等可见事实；商店宣传截图只作构图参考，点击路径需另验。最后把自己的稿和参照并排，若拿掉名字仍像同一产品，重新安排构图、图形或品牌表达。
- 做第一屏前点清主图从哪里来、是否获准商用、裁切后是否保留决定性细节。地标、失物、场地实况等事实用对应实拍或可信业务资料。可以生成氛围插画；示意图和演示数据标明用途。按已确认方案和预算使用现有素材、生图能力或有许可的图库；素材暂缺时先用可独立使用的图文简版，告诉用户缺哪张图，避免把虚构照片当作证据。
- 功能图标优先项目同套图标或腾讯组件库；缺少的业务图标自行绘制并留源稿。默认不使用 emoji，正式运行素材按显示尺寸导出压缩的小写 png、jpg。优先让文字可读可选，价格、状态、地址等关键信息保留原生文本。设计装饰不值得额外权限或大包时，用原生控件表达。

## 同题出稿，再看图改一轮

三版共用一个关键页面、同一批合成或脱敏业务数据、相同状态及功能、同一微信组件体系。每版至少呈现一次真实决策，标签用任务语言命名。用「给谁更省事、哪里会多一步、小程序如何实现」给出首选。选定后把有效的版式、素材来源、组件映射和已否决的方向写进项目既有设计记录，其他页面复用同一套状态色、字级和动作习惯。

出示候选前按手机原尺寸逐版看；完整原型再走一条主路径。先找第一眼会看错哪里，再在最难的状态里看一遍，例如最后一个余位、缺图、超长地名。优先修影响任务的一两处，同尺寸复看并说清哪处实际改了；已满足的版式保留。可截图时留前后图，有查看器就实际看图；只有源码时列出可验证的结构与待看的页面。开发后拿同一条数据走微信实页，按[视觉回归说明](visual-regression.md)比对，并实点决定成败的一步。原型截图、模拟器点击和手机实测分别记录。
